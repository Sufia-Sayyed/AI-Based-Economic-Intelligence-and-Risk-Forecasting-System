# AI-Based-Economic-Intelligence-and-Risk-Forecasting-System
This project uses AI techniques to analyze and forecast key economic indicators like GDP, inflation, and unemployment. By combining machine learning, time series methods, and risk detection, it uncovers trends and provides insights into possible economic risks.

# 🚀 Overview

This project is an AI-based system designed to analyze and forecast key economic indicators such as GDP growth, inflation rate, and unemployment rate. Using historical data spanning 50 years, the system applies machine learning and time series techniques to identify trends and assess potential economic risks.

# 🎯 Features
📈 Forecasts GDP, inflation, and unemployment
🤖 Uses machine learning and time series models
⚠️ Detects potential economic risks
📊 Interactive web app built with Streamlit
📉 Analyzes long-term historical economic data
🗂️ Project Structure
├── economic_intelligence_app.py   # Main Streamlit application
├── requirements.txt              # Required libraries
├── dataset.csv                   # 50-year economic dataset
⚙️ Installation

# Clone the repository:
git clone https://github.com/your-username/your-repo-name.git
cd your-repo-name
Install dependencies:
pip install -r requirements.txt

▶️ How to Run
# Run the Streamlit app using:
streamlit run economic_intelligence_app.py

# 📊 Dataset
The dataset contains 50 years of historical economic data used to train and evaluate the models. It includes key indicators such as GDP, inflation, and unemployment.
